# Product

## Register

product

## Users

Field engineers demonstrate CodeRabbit Security to developers, reviewers, and security leaders. A presenter uses a laptop in a bright meeting room. The audience must read the screen and follow each action without narration.

## Product Purpose

Harbor Support is a local support and billing application with fifteen executable security lessons. Each lesson compares an insecure implementation with a secure one. The main story follows a missing account check in invoice access from a local review to PR review, Jira, Deep Scan, verification, and remediation.

## Brand Personality

Clear, practical, composed. Explanations use short sentences and precise terms.

## Anti references

Avoid a wall of vulnerability cards, decorative security imagery, unreadable terminal text, and dashboards with invented scan metrics.

## Design Principles

- Show the business task before the security category.
- Keep the request, result, code, and explanation close together.
- Make account boundaries visible.
- Display observed product evidence separately from local lesson results.
- Provide repeatable actions and explicit reset controls.

## Accessibility and Inclusion

Target WCAG 2.2 AA. Use large readable type, keyboard controls, visible focus, text status labels, sufficient contrast, reduced motion, and responsive layouts.
